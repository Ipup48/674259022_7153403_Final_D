# Frontend: ระบบจัดการกิจกรรม (Event Management)

- **ผู้จัดทำ**: นายวุฒิชัย จันทร์มีชัย
- **ชุดโจทย์ที่ 4**: กิจกรรม (`events` / `/api/events`)
- **หมวดหมู่ D**: อบรม, สัมมนา, จิตอาสา

## คำสั่งการรัน
```bash
npm install
npm run dev
```

## Environment Variables
- `VITE_API_URL`: URL ของ Backend เช่น `http://localhost:5000/api/events` หรือ URL บน Render
